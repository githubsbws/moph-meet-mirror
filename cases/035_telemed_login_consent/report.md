# Case 035: Consent ก่อนใช้ระบบแพทย์ทางไกล

## แหล่งข้อมูล

นำสาระจากเอกสาร `Telemed Consent Document from thongthatty.docx` มาแสดงในรูปแบบสรุปที่อ่านง่ายก่อนเข้าสู่ระบบ: ข้อมูลที่ประมวลผล, วัตถุประสงค์, ระยะเวลาเก็บข้อมูล 10 ปี, สิทธิถอนความยินยอม และช่องทางติดต่อสำนักสุขภาพดิจิทัล/DPO

## การทำงาน

- หลัง login ผ่านเว็บหรือแอปมือถือ ผู้ใช้ถูกส่งไปหน้า consent ก่อน Dashboard
- ปุ่มยืนยันเปิดใช้ได้เมื่อเลือก checkbox ว่าอ่านและเข้าใจแล้ว
- เลือกไม่ยินยอมจะบันทึกผลแล้วออกจากระบบ
- บันทึก `username`, เวอร์ชันเอกสาร, ผลการตัดสินใจ และเวลา ทั้งสถานะล่าสุดและ audit event
- API ที่ยืนยันตัวตนจะตอบ `428 telemedConsentRequired` จนกว่าจะมีการยินยอมสำหรับเวอร์ชันปัจจุบัน

## การดูแลเวอร์ชัน

ค่าเริ่มต้นคือ `telemed-consent-v1` และเปลี่ยนได้ด้วย `TELEMED_CONSENT_VERSION` หากข้อความเอกสารถูกแก้ไข การเปลี่ยนเวอร์ชันจะบังคับให้อ่านและยืนยันใหม่

## การตรวจสอบ

ทดสอบบน core แบบ memory แล้ว: API ทั่วไปถูกปฏิเสธก่อน consent, endpoint consent อ่าน/บันทึกได้, และ API ใช้งานได้หลังตอบรับ
