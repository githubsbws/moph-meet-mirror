# Case 023: ปรับขอบเขต H-Code สำหรับการค้นหาบุคลากร

## ปัญหา

`GET /api/providers` บังคับให้มี H-Code กับผู้เรียกทุกบทบาท จึงทำให้แอดมินที่ไม่มี H-Code ใช้งาน URL เช่น `/api/providers?q=tes&limit=10` ไม่ได้ และได้รับ `hcodeRequired` ทั้งที่การค้นหารายชื่อรวมเป็นสิทธิ์ของแอดมิน

## การแก้ไข

- แอดมินค้นหารายชื่อบุคลากรในข้อมูลภายในระบบได้ทุก H-Code เมื่อไม่ได้ระบุ `hcode`
- แอดมินระบุ `?hcode=...` เพื่อจำกัดผลลัพธ์เป็นสถานพยาบาลเดียวได้
- ผู้ใช้ทั่วไปที่มี H-Code ยังค้นหาได้เฉพาะ H-Code ของตน เพื่อคงการแยกข้อมูลตามสถานพยาบาล
- ผู้ใช้ทั่วไปที่ไม่มี H-Code ได้ผลลัพธ์ว่าง (`200 []`) แทน error และไม่ถูกเปิดเผยสมุดรายชื่อรวมข้ามสถานพยาบาล
- รองรับนโยบายนี้ทั้ง memory, SQLite และ PostgreSQL store

## การตรวจสอบ

- `node --check` สำหรับ API และ store ทั้งสามผ่าน
- `git diff --check` ผ่าน
- เปิด core ด้วย memory store แล้ว login แอดมินที่ไม่มี H-Code และเรียก `/api/providers?q=tes&limit=10`: ได้ HTTP `200` และพบ `Test User` 1 รายการ

## หมายเหตุ

`hcodeRequired` ที่เหลือใน Dashboard ใช้เฉพาะผู้ใช้ทั่วไป เพราะเป็นข้อกำหนด Data Isolation by Hospital; แอดมินยังดูภาพรวมและกรอง H-Code เองได้
