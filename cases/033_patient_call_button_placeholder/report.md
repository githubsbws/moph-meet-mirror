# Case 033: ปุ่มเรียกผู้ป่วยตามนัด (UI placeholder)

> สถานะนี้ถูกแทนที่แล้วโดย Case 034: ปุ่มเรียกผู้ป่วยเชื่อมกับ flow ภายในระบบจริง

## สิ่งที่เพิ่ม

- หน้าเว็บห้องตรวจมีแท็บ `ผู้ป่วยนัด` แสดง patient invitation ทั้งหมด พร้อมสถานะจากข้อมูลห้องตรวจเดิม
- แอปมือถือหน้าควบคุมห้องตรวจมีปุ่ม `เรียกผู้ป่วยตามนัด` และรายการเลือกผู้ป่วย
- กดปุ่มรายบุคคลแล้วจะเพียงเลือกและแสดงว่ากำลังเตรียมเรียกผู้ป่วยรายนั้น

## สถานะที่แสดง

- ยังไม่เข้าห้องรอ
- พร้อม (เข้าห้องรอแล้ว)
- กำลังตรวจ / ตรวจเสร็จ
- ยกเลิกแล้ว / ไม่มาตามนัด

ปุ่มกดได้เฉพาะรายการสถานะ `พร้อม` ซึ่งหมายถึงเข้าห้องรอแล้วและเป็นสัญญาณที่ระบบมีอยู่แล้วว่าผู้ป่วยพร้อม; ปุ่มถูกปิดสำหรับผู้ที่ยังไม่เข้าห้องรอ กำลังตรวจ ตรวจเสร็จ ยกเลิก หรือไม่มาตามนัด

## ขอบเขตเดิม

เดิมการกดปุ่มไม่มี network request, ไม่ส่ง notification, ไม่เปิดห้องวิดีโอ และไม่เปลี่ยนสถานะคิว ภายหลังได้เปลี่ยนตาม Case 034 เป็น flow ภายในระบบ: `waiting` → `called` → ผู้ป่วยยืนยันเข้า → `admitted` โดยไม่ใช้ Calling API ภายนอก
