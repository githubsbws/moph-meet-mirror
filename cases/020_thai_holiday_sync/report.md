# รายงานการเชื่อมปฏิทินวันหยุดราชการไทย

## สิ่งที่เพิ่ม

- เชื่อม API วันหยุดไทย `https://thailandformats.com/api/v1/holidays/{year}`
- เก็บข้อมูลวันหยุดรายปีลง storage ของระบบ (SQLite, PostgreSQL หรือ memory สำหรับทดสอบ)
- `GET /api/holidays?year=YYYY` คืนข้อมูลจาก cache; หากยังไม่มี จะ sync ครั้งแรกให้
- `POST /api/holidays/sync` ให้ผู้ดูแลระบบสั่ง sync ปีที่ต้องการอีกครั้งได้
- ขยายช่วงวันหยุดหลายวันเป็นวันที่แยกกัน เพื่อทำเครื่องหมายในปฏิทินได้ถูกต้อง
- Dashboard Web แสดงวันหยุดด้วยตัวเลขสีแดงและจุดแดง พร้อมชื่อวันหยุดใน tooltip

## การทำงานเมื่อแหล่งข้อมูลขัดข้อง

- หากมี cache ของปีนั้น ระบบยังคืนข้อมูลที่ sync ไว้ล่าสุดได้
- หากยังไม่มี cache และต้นทางเรียกไม่ได้ ระบบตอบ `503 holidaySyncUnavailable` โดยไม่ทำให้ Dashboard ล่ม

## การตรวจสอบ

- ตรวจ syntax ของ Core, storage adapters และ JavaScript ปฏิทิน
- ทดสอบกับ Core memory store และข้อมูลปี 2026: การเรียกครั้งแรกสำเร็จและได้ 23 วันที่แสดงบนปฏิทิน (รวมวันหยุดหลายวัน); การเรียกซ้ำคืนข้อมูลจาก cache
