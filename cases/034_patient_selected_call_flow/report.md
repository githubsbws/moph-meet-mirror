# Case 034: แพทย์เรียกผู้ป่วยรายที่เลือก และผู้ป่วยยืนยันเข้าห้องตรวจ

## Flow ที่ทำ

1. ผู้ป่วยเปิดลิงก์นัดและอยู่ในสถานะ `waiting` (แสดงว่า `พร้อม`)
2. แพทย์กดเรียกผู้ป่วยรายนั้นจากรายการนัด ระบบเปลี่ยนเป็น `called`
3. หน้าคิวของผู้ป่วยแสดงข้อความว่าแพทย์เรียกแล้ว พร้อมปุ่ม `เข้าห้องตรวจ`
4. ผู้ป่วยกดยืนยัน ระบบเปลี่ยนเป็น `admitted` แล้วเปิดห้อง Jitsi

## API ภายในระบบ

- `POST /api/exam/:id/call/:entryId` สำหรับแพทย์เรียกผู้ป่วยที่พร้อม
- `POST /api/exam/:id/queue/enter` สำหรับผู้ป่วยยืนยันการเข้าห้อง โดยยืนยันสิทธิ์ด้วย JWT จากลิงก์นัด

ไม่ใช้ Calling API, LINE, MOPH Alert หรือ notification ภายนอก

## กติกาสถานะ

- เรียกได้เฉพาะผู้ป่วย `waiting`
- มีผู้ป่วยที่รอกดเข้าห้องได้ครั้งละหนึ่งคน (`called`)
- หากแพทย์เลือกเรียกคนใหม่ก่อนผู้ป่วยคนเดิมเข้าห้อง คนเดิมกลับเป็น `waiting`
- เมื่อมีผู้ป่วย `admitted` อยู่แล้ว ระบบปฏิเสธการเรียกคนใหม่

## การทดสอบที่เพิ่ม

ชุดทดสอบ API ทั้ง JavaScript และ Python ครอบคลุม: ผู้ป่วยเข้าคิว → แพทย์เรียกด้วย invitation ที่ระบุ → ผู้ป่วยกดเข้าห้อง → ได้สถานะ `admitted`
