# รายงานการปิดงาน Flow เชิญพร้อมสร้างห้องและ Mobile Waiting Room

## สิ่งที่เพิ่ม

- ห้องตรวจรองรับการส่ง `patientName` และ `patientCid` ในคำขอสร้างห้องเดียวกับรายชื่อแพทย์/พยาบาล
- CID ผู้ป่วยตรวจ 13 หลักพร้อม checksum ก่อนสร้างห้อง และเก็บเฉพาะ hash ในข้อมูลคำเชิญ
- ผลลัพธ์หลังสร้างห้องแสดงลิงก์ผู้ป่วยเฉพาะเมื่อมีการเชิญพร้อมสร้างห้อง
- Web เพิ่มส่วน “เชิญผู้ป่วยพร้อมสร้างห้อง” ในฟอร์มห้องตรวจ
- Mobile เพิ่มช่องชื่อผู้ป่วย/CID ในฟอร์มสร้างห้องตรวจ และส่ง payload เดียวกันกับ Web
- Mobile เพิ่มปุ่ม Waiting Room สำหรับผู้จัดการห้องประชุม Public: สร้างลิงก์เฉพาะผู้รับ, แชร์ลิงก์, โหลดรายชื่อ และอนุมัติ/ปฏิเสธผู้รอ

## การตรวจสอบ

- ตรวจ Core และ Web JavaScript ด้วย syntax check
- ตรวจ Mobile ด้วย `npx tsc --noEmit`
- ตรวจ `git diff --check`
- Smoke test API: สร้างห้องตรวจพร้อมผู้ป่วยสำเร็จ, ได้ลิงก์คำเชิญ, สถานะคำเชิญ active และไม่มี CID ดิบในข้อมูลห้อง
- ตรวจฟอร์ม Web ผ่าน browser: แสดงช่องชื่อผู้ป่วย/CID เฉพาะห้องตรวจและไม่พบ console error
