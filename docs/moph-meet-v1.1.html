📋 ภาพรวมระบบ

MOPH Meet คือแพลตฟอร์มแพทย์ทางไกล (Telemedicine) ของกระทรวงสาธารณสุข ออกแบบมาเพื่อให้บุคลากรทางการแพทย์สามารถ ตรวจรักษาผู้ป่วยผ่านวิดีโอคอล ได้อย่างปลอดภัยและสะดวก โดยรองรับการยืนยันตัวตนผ่าน ProviderID (Health ID) ของ สธ.

📋 Overview

MOPH Meet is the official telemedicine platform of Thailand's Ministry of Public Health (MOPH), enabling healthcare providers to consult patients via secure video calls. Providers authenticate through ProviderID (Health ID), the MOPH's centralized identity system.

🩺

Online Exam Rooms

Doctors create rooms, share invite links, and manage patient queues

🔗

HIS Integration

Appointment systems call the API to pre-create rooms automatically

📊

Usage Dashboard

Real-time usage statistics, publicly accessible for transparency

📱

Multi-device

Works on any browser + mobile app (coming soon)

Key Highlights

  • Patients require no app install or registration — one click to join
  • Video via self-hosted open-source platform — data stays within MOPH infrastructure
  • Provider authentication through ProviderID, MOPH's central identity
  • Built-in patient queue system for online OPD workflows
  • HIS integration via standard REST API

✨ ฟีเจอร์หลัก

สำหรับแพทย์ / บุคลากร

  • 🔐 เข้าสู่ระบบด้วย ProviderID (OAuth 2.0)
  • 🏥 สร้างห้องตรวจ (Exam Room) พร้อมลิงก์เชิญผู้ป่วย
  • 👥 ระบบคิว — เรียกผู้ป่วยเข้าตรวจทีละราย
  • 📋 Dashboard แสดงห้องตรวจทั้งหมดของตนเอง
  • 🤝 แพทย์หลายคนร่วมห้องเดียวกันได้ (Co-provider)
  • 🤖 สรุปผลตรวจอัตโนมัติด้วย AI Beta

สำหรับผู้ป่วย

  • 📎 คลิกลิงก์เข้าคิวรอตรวจ — ไม่ต้องสมัครหรือติดตั้ง
  • 📺 หน้าคิวแสดงลำดับ + แจ้งเตือนเมื่อถึงคิว
  • 🎥 วิดีโอคอลคุณภาพสูง ปรับตามแบนด์วิดท์

สำหรับระบบ HIS / ผู้บูรณาการ

  • 📡 REST API สร้างห้องตรวจล่วงหน้า (POST /api/meet/reserved)
  • 🎫 สร้างลิงก์ผู้ป่วยเพิ่มเติม (POST /api/meet/reserved/token)
  • ⏳ ลิงก์มีอายุถึง 24 ชม. หลังเวลานัด — ไม่หมดอายุก่อนเวลา

✨ Core Features

For Providers (Doctors / Staff)

  • 🔐 Sign in with ProviderID (OAuth 2.0)
  • 🏥 Create exam rooms with instant patient invite links
  • 👥 Queue system — call patients in one at a time
  • 📋 Personal dashboard showing all active rooms
  • 🤝 Multiple providers can join the same room (co-provider)
  • 🤖 AI-powered consultation summary Beta

For Patients

  • 📎 Click a link to join the queue — no signup or install needed
  • 📺 Queue screen shows position + notification when it's your turn
  • 🎥 High-quality adaptive video calling

For HIS / Integrators

  • 📡 REST API to pre-create exam rooms (POST /api/meet/reserved)
  • 🎫 Generate additional patient links (POST /api/meet/reserved/token)
  • ⏳ Links valid until 24 hours after scheduled end time

🔒 ความปลอดภัยและความเป็นส่วนตัว

  • การเข้ารหัส: วิดีโอคอลเข้ารหัสแบบ End-to-End (SRTP)
  • การยืนยันตัวตน: แพทย์ยืนยันผ่าน ProviderID (OAuth 2.0) — ไม่เก็บรหัสผ่าน
  • Token ผู้ป่วย: ใช้ JWT ที่มีอายุจำกัด ผูกกับห้องตรวจเฉพาะ
  • ข้อมูลชั่วคราว: ห้องตรวจและข้อมูลเซสชันลบอัตโนมัติหลัง 25 ชม.
  • ข้อมูลอยู่ในไทย: เซิร์ฟเวอร์ตั้งอยู่ภายในโครงสร้าง สธ. ผ่าน Cloudflare WAF
  • ไม่เก็บวิดีโอ: ระบบไม่บันทึกวิดีโอคอลโดยค่าเริ่มต้น

🔒 Security & Privacy

  • Encryption: Video calls encrypted via SRTP through self-hosted media server
  • Authentication: Providers authenticate via ProviderID (OAuth 2.0) — no passwords stored
  • Patient Tokens: JWT with limited lifetime, bound to specific rooms
  • Ephemeral Data: Rooms and session data auto-deleted after 25 hours
  • Data Residency: Servers hosted within MOPH infrastructure, protected by Cloudflare WAF
  • No Recording: Video calls are not recorded by default
